# Requests from lane E2 (Wi-Fi Aware transport)

## 1. Make `LinkMessageType` package-visible in StarlingLocalP2P (Orchestrator, low priority)

**What:** in `Packages/StarlingTransport/Sources/StarlingLocalP2P/LinkProtocol.swift`, change `enum LinkMessageType: Int` to `package enum LinkMessageType: Int`.

**Why:** the Wi-Fi Aware transport speaks the same link protocol as LocalP2P (ADR 0110): `LinkHello`, then frames, with TLV types 1 and 2. `LinkHello`, `DialRule`, `RetryPolicy`, and `LinkArbiter` are already `package`, but the message type enum is internal, so the two targets cannot share it.

**Meanwhile:** `StarlingWiFiAware` defines `AwareMessageType` with the same two values. Nothing is blocked. Once the enum is shared, E2 replaces its copy in one small commit.
