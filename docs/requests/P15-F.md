## Executable integration evidence

The simulator target reports 82 tests in 15 suites, with no known issue
expectations. It includes 49 earlier Core/component
contracts and 33 new real implementation tests. Parameterized cases expand
those counts further.

- **Pick a place:** real service over authenticated Simulation and Outbox with
  the same ConversationLedger. Explicit audience exclusions cause no request
  traffic. Recipient policy exclusion and silence use the same injected answer
  deadline. A pass and an untouched card reveal no different query replies,
  admission slots after restart, or early confirmation. Final rosters shorten
  at the same deadline. Candidate budgets survive service replacement; a 17th
  candidate sends nothing. Private budget conflicts send ordinary noOverlap,
  reserve candidates, and retire. Never permits exact-offer acceptance. Location
  denial completes with a typed venue. Hostile names stay out of model facts;
  mislabeled Maps identifiers and unsolicited proposals produce no card.
- **Find a time:** two real services complete with a denied-calendar starter
  and calendar invitee. Denied, restricted, write-only, and not-determined
  invitees ask the owner without requesting permission. Calendar marker strings
  appear in no frame, checkpoint, consent, lifecycle event, or model facts.
  Old proposal rounds, wrong mode, and incompatible versions cannot replace the
  current card. A pass remains retired after restore. A retained 16-candidate
  ledger blocks a new oracle answer even when interaction/checkpoint state is
  lost. A current acceptance denial ends blockedByPrivacy; an old denial after
  a newer proposal is dropped.
- **Chaining and Swap photos:** suggestions, start consent, stale capability
  checks, Never changes, opt-out after scheduler hand-over, and store replacement
  use the real planner/scheduler. Invalid parent metadata is denied before any
  consent or journal entry. Authenticated malformed photo offers, outsiders,
  invented parents, quiet mode, extra topics, and counts above 24 open nothing.
  A genuine offer opens only an invitee card. A scheduled owner pick sends only
  its count to final attendees and records the actual consent items. Passing
  retires the offer; replay after service replacement opens nothing. The
  attendee-update and timeline membership regressions for #66 and #67 pass.
- **Retirement ordering:** held and failed retirement writes exercise the real
  place, time, and photo services. No clean pass is emitted before the write
  completes; a thrown write reports failure. These service cases supplement the
  real secure-queue cancellation and global cancelInFlight contracts.
- **Audit and storage:** real EgressRecorder converts interrupted journal entries
  to unknown after replacement, retries failed sink writes idempotently, and
  stops transport when the journal fails. Unknown versions make no Kept claims.
  The actual FileConversationLedger retains an old retired ID after 300 newer
  entries and retains candidate budgets after reopening. A write failure after
  loading valid state latches it closed. FileSentSequenceStore reopens with
  independent recipient high-water marks.

## Earlier Core and component coverage

ADRs 0250 to 0252 record the method. The existing cases cover injection vectors,
forged identities, unsolicited skill metadata, consent request replay, all final
states, mode/v1 fail-closed decoding, audience precedence, privacy defaults,
seven yes/no and exact-acceptance value shapes, cloud consent, cumulative ledger
budgets, journal refusal, late policy changes, and per-recipient sequences.

A last policy change to Never produces OutboxError.denied; Share changing to
Ask me produces policyChangedDuringConsent. Both stop before numbering. An
unchanged approval and relaxed policy remain positive controls. cancelInFlight
stops all four waiting conversation/recipient scopes. A failed retirement write
still cancels the offer waiting in the real secure channel. The one-number gap
after transport cancellation plus rollback restart is explicitly accepted by
ADR 0021 amendment 11.

## Remaining adapters and evidence limits

[Issue #49](https://github.com/oliverrowebardeen/starling-ios/issues/49) remains the
cross-lane integration list. Its unchecked multi-lane rows are not declared
complete by one skill's passing subset. Still required:

- The new Down for service, especially quiet inbound symmetry, mode/audience
  parsing, and the same timing when an asker is excluded. ADR 0011 amendment 17
  makes quiet asks one-to-one: one friend's answers must not affect another's
  messages or schedule. A group plan needs a separate explicit Invite with
  the roster under People. Amendment 16 sends card passes through the service;
  the coordinator hides the card locally without ending its delivery schedule.
- A's follow-up wiring: installed skill factory, permission sheets, on-disk
  EgressJournal and recovery before audit display, ChainedFromPolicy, scheduler
  claims, and the coordinator as the serialized EgressSink.
- App-level consent suspension/recovery with real services, stricter settings
  installation plus cancellation, audience/settings recovery races, and every
  service terminal path. Current gate tests cover passes, not every ending.
- Device UI, real EventKit/MapKit/system picker behavior, and opt-in real-model
  injection measurement (`STARLING_MODEL_TESTS=1`). Swap photos is still flagged
  off and sends a count, not photo bytes. Its picker does not request library
  permission; cancelling or selecting nothing produces no offer (ADR 0242).

Run `Tools/test-all.sh Tools/Simulator`. Tests create their own Outbox on the
Simulation agent's exposed secure channel because SimulatedAgent.send has no
skill metadata parameters. The original Inbox remains the sole event consumer;
a behavior relay hands accepted messages to the real services. Test-only
coordinators apply events to InMemoryInteractionStore and are not claimed as the
app coordinator. In-memory journal replacement tests E's recovery logic, not
filesystem crash durability. The separate file-ledger test uses actual storage.
